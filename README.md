# ZH Dairy

A lightweight and optimized dairy farming system developed for RedM.

The resource allows players to collect milk through configurable interaction points while keeping all critical gameplay logic validated on the server side.

## Features

- Milk collection system
- Configurable locations
- Optimized client loops
- Server-side validation
- Configurable rewards
- Easy configuration
- Lightweight resource
- Standalone architecture

- ## Technologies

- Lua
- RedM
- Standalone
